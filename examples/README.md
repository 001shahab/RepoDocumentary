# Examples

These were generated with the built-in offline narrator, so you can reproduce them
exactly without an API key:

```bash
repodoc https://github.com/pallets/itsdangerous --offline --anonymize --style noir \
  -o examples/itsdangerous-noir-offline.md
```

The OpenAI narrator produces far livelier scripts from the same facts. Try it on your
own project with `repodoc --style noir`.
